# Kasvera

Kasvera is a personal finance tracker built with HTML, CSS, and JavaScript. It helps users record transactions and monitor their finances through a simple dashboard.

## Features

- Track income and expenses
- View total balance, income, and expenses
- Add, edit, and delete transactions
- Search and filter transactions
- Set a monthly budget
- View transaction summaries by category
- Visualize financial data with a chart
- Save transaction data in the browser using localStorage
- Responsive layout for desktop and mobile

## Technologies

- HTML
- CSS
- JavaScript
- localStorage
